# SortOut — Free vs Pro

SortOut is free to use. **SortOut Pro** unlocks three advanced algorithms.
Everything can be *previewed* for free — you only need Pro to *apply* a Pro
plan, so you can see exactly what you are paying for.

| Feature | Free | Pro |
|---|:---:|:---:|
| By File Type, Smart Name Grouping, Custom Pattern, Move All Together | ✅ | ✅ |
| Date Organizer, By File Size, Keyword Tagger | ✅ | ✅ |
| Preview of every algorithm (incl. Pro) | ✅ | ✅ |
| Duplicate Finder (SHA-256, recoverable space) | 👀 preview | ✅ |
| Project / Code Detector | 👀 preview | ✅ |
| AI Grouping (OpenAI / Gemini / local Ollama) | 👀 preview | ✅ |
| Profiles (3 built-in + your own) | ✅ | ✅ |
| One-click revert + operation history | ✅ | ✅ |
| Inline folder rename, filter, stats bar | ✅ | ✅ |
| Dark mode | ✅ | ✅ |
| `.sortout-ignore` rules | ✅ | ✅ |
| Command line incl. `--dry-run` JSON | ✅ | ✅ |

## Getting Pro
1. Open **Help → Enter License Key** in SortOut and click **Copy** next to your
   *Machine ID* (or run `SortOut.exe --machine-id`).
2. Buy SortOut Pro via the **Get Pro** button (opens the store page) and include
   your Machine ID.
3. You receive a key like `SORTOUT-PRO-ABCD2345`. Paste it into
   **Help → Enter License Key → Activate**, or run
   `SortOut.exe --activate SORTOUT-PRO-ABCD2345`.

Keys are bound to one computer and work offline. Need to move to a new PC?
Contact support with your old and new Machine IDs.

## Privacy
- No telemetry. Activation sends only the key, Machine ID (an anonymous hash),
  product and version to the validation server, and works offline when it is
  unreachable.
- AI Grouping sends **file names only** (never contents) to the provider you
  choose — or nothing leaves your PC if you use local Ollama.
